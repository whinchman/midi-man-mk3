## Description

`ctrl_rx: Receiver<MidiCtrlMsg>` channel. Replace the simple blocking
`recv()` loop with a dual-channel polling loop using `try_recv` / `recv_timeout`.

`choose_midi_port` and `choose_midi_channel`.

Files to touch: `engine/src/midi_out.rs`

**Add `MidiCtrlMsg` enum (public, always compiled — no feature gate):**
```rust
/// Runtime control messages for the MIDI output thread.
pub enum MidiCtrlMsg {
    /// Switch to the port whose name contains this substring (case-insensitive).
    ChangePort(String),
    /// Set the MIDI channel (1-indexed; the actual channel byte update happens
    /// via InputCommand::ChannelSet in the state processor).
    ChangeChannel(u8),
}
```

**Update `run_midi_out` signature:**
```rust
pub fn run_midi_out(
    rx: Receiver<MidiEvent>,
    ctrl_rx: Receiver<MidiCtrlMsg>,
    port_name: Option<String>,
)
```

**Rewrite the internal event loop** (inside `run_midi_out`) to poll `ctrl_rx`
non-blockingly on each iteration before doing a 50ms timeout recv on `rx`:

```rust
use std::sync::mpsc::TryRecvError;
use std::time::Duration;

loop {
    // Non-blocking ctrl check first.
    match ctrl_rx.try_recv() {
        Ok(MidiCtrlMsg::ChangePort(name)) => {
            sender = open_port(Some(&name));
        }
        Ok(MidiCtrlMsg::ChangeChannel(_)) => {
            // Channel is applied at the MidiEvent level via state.midi_channel.
            // This message is informational only for the midi_out thread.
        }
        Err(TryRecvError::Empty) => {}
        Err(TryRecvError::Disconnected) => break,
    }
    // Blocking recv with 50ms timeout on MIDI events.
    match rx.recv_timeout(Duration::from_millis(50)) {
        Ok(event) => {
            if let Some(ref mut s) = sender {
                dispatch(s, &event);
            }
        }
        Err(RecvTimeoutError::Timeout) => continue,
        Err(RecvTimeoutError::Disconnected) => break,
    }
}
```

`open_port` already returns `Option<Box<dyn MidiSender>>` — reuse it.
Dropping the old `sender` on port swap is intentional (ALSA flushes on drop).
