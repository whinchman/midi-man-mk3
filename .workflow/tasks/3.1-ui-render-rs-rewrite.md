## Description

Fully rewrite `engine/src/ui_render.rs`. Replace the existing overlay-based
render logic with a 7-zone vertical stack layout using a cyberpunk color palette.
Define the `UiLocalSnapshot`, `LogEntry`, and `LogTag` structs in this file
(no `hw-io` feature gate) so that `ui.rs` can import them without compilation
gating issues.

Files to touch: `engine/src/ui_render.rs`

**New public structs defined in this file:**

```rust
use std::collections::VecDeque;

/// Snapshot of UI-local state passed to render_frame each frame.
/// Defined here (no hw-io gate) so ui.rs can import without feature gating.
pub struct UiLocalSnapshot<'a> {
    pub focus: crate::input::FocusPanel,

pub struct LogEntry {
```

**Layout (7 zones, `Direction::Vertical`, applied to full terminal area):**

```rust
let chunks = Layout::vertical([
    Constraint::Length(1),   // [0] Title bar
    Constraint::Length(1),   // [1] Transport bar
    Constraint::Min(5),      // [2] F1·SEQ panel
    Constraint::Length(3),   // [3] F2·SEQ PARAMS panel
    Constraint::Length(3),   // [4] F3·RANDOM PARAMS panel
    Constraint::Min(5),      // [5] F4·CLI panel
    Constraint::Length(1),   // [6] Bottom keybind bar
]).split(frame.area());
```

**Zone render functions (private, called from `render_frame`):**

- `fn render_title_bar(frame, state, ui, area: Rect)`:
  - Left: `"▶ 217 Industries / midi-man-mk3"` — `"midi-man-mk3"` in `FUCHSIA`
  - Right: `"MIDI OUT <device> CH:<n>"` using `ui.midi_device_name` and `ui.midi_channel_display`
  - Assemble as a `Line` with `Span`s of different styles using `Paragraph`

- `fn render_transport_bar(frame, state, area: Rect)`:
  - Single line: `"BPM <n>  KEY <k>  MODE <m>  STEP <s>  STATUS ► <state>"`
  - STATUS colored `GREEN` when playing, `CYAN` when paused, default when stopped
  - Reuse existing helper functions: `key_name`, `mode_name`, `status_label`

- `fn render_seq_panel(frame, state, ui, area: Rect)`:
  - Bordered block title `"F1 · SEQ"`, border `CYAN` when `ui.focus == FocusPanel::Sequencer`, else `DIM_CYAN`
  - Inner area: `Layout::horizontal([Constraint::Ratio(1, 16); 16])`
  - Each column rendered as a `Block` + `Paragraph` with 3 rows of content:
    - Row 0: step number (1-indexed) in `GRAY`
    - Row 1: note name centered (reuse `key_name` or define note display helper)
    - Row 2: `"●"` enabled indicator
  - Color per step:
    - Playhead step (state.step_idx): border + text `MAGENTA`
    - Enabled non-playhead: `CYAN`
    - Disabled: `DIM_CYAN`
    - Selected cursor (ui.selected_step): add `MAGENTA` outline/underline

- `fn render_seq_params_panel(frame, state, ui, area: Rect)`:
  - Bordered block `"F2 · SEQ PARAMS"`, border highlight when `ui.focus == SeqParams`
  - Single content row with all params inline; selected param (`ui.seq_param_idx`) bold + `MAGENTA`
  - Params: KEY, MODE, SWING, STEP, L.IN, L.OUT, PAUSE, PLAY
  - Reuse `param_value_string`, `pending_param_value_string`, `shift_param_value_string` as applicable

- `fn render_rand_params_panel(frame, state, ui, area: Rect)`:
  - Bordered block `"F3 · RANDOM PARAMS"`, border highlight when `ui.focus == RandParams`
  - Params: N.RND, T.RND, ROLL, V.MAX, T.TYPE, S.RND, S.QUANT, SEED
  - SEED displayed as `format!("0x{:04X}", state.rand_seed)` (uses new `rand_seed` field from Task 1.1)
  - Selected param (`ui.rand_param_idx`) bold + `MAGENTA`

- `fn render_cli_panel(frame, ui, area: Rect)`:
  - Bordered block `"F4 · CLI"`, border highlight when `ui.focus == Cli`
  - Inner area: top portion = log lines (last N that fit); bottom 1 row = `"> <cli_line>_"`
  - Log timestamp in `GRAY`, tag in `CYAN`/`GREEN`/red/default based on `LogTag`
  - Always show last N entries that fit (calculate from area height minus 1 for input row and 2 for borders)

- `fn render_keybind_bar(frame, area: Rect)`:
  - Static `Paragraph` in `DIM_CYAN`:
    `"F1-F4 focus | P play | +/- BPM | ←/→ param | ↑/↓ adjust | space toggle | enter confirm | esc cancel | ^C quit"`

## Context

- `engine/src/ui_render.rs`: currently 17K with old layout — full rewrite, keep only the helper functions listed above.
- ratatui 0.30 already in `Cargo.toml`. Use `Color::Rgb(r, g, b)`, `Constraint::Ratio`, `Layout::horizontal()`, `Layout::vertical()`, `Paragraph`, `Block`, `Borders`, `Style`, `Span`, `Line`.
- `FocusPanel` is imported from `crate::input` (defined in Task 2.1).
- `SequencerState` has `step_idx: usize` (current playhead step), `tempo_bpm: u16`, and all param fields. Read the existing file to identify exact field names before writing render functions.
- No heap allocation in the render hot path — use stack-allocated `Line`/`Span` arrays where possible; `Paragraph` + ratatui widgets handle their own allocation.
- Code standards: Rust stable edition 2021, safe Rust only, no `unwrap()` in non-test code, clippy must pass, rustfmt.
