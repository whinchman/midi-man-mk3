## Description

Add two new fields to `SequencerState` and four new `InputCommand` variants with
their `apply_command` handlers. This is the foundation layer — all other tasks
in Phase 2 and beyond depend on these types existing.

Files to touch: `engine/src/state.rs`, `engine/src/input.rs`

**`SequencerState` new fields** (add to struct definition and `Default` impl):

```rust
/// User-facing random seed (lower 32 bits of rng_seed, settable via CLI).
pub rand_seed: u32,          // default: 0x853C_49E6
/// Name of the connected MIDI output port (for title bar display).
pub midi_device_name: String, // default: String::new()
```

**`InputCommand` new variants** (add to `engine/src/input.rs`):

```rust
/// Adjust BPM by signed delta (clamped to 20–300). Always active.
BpmDelta(i8),
/// Set the random seed from CLI. Updates both rand_seed and rng_seed.
SeedSet(u32),
/// Set MIDI channel (1-indexed input; stored 0-indexed). Sent by CLI handler.
ChannelSet(u8),
/// Sync the MIDI device name into state for title bar display.
MidiDeviceName(String),
```

**`apply_command` handlers** to add in `engine/src/state.rs`:

```rust
InputCommand::BpmDelta(d) => {
    self.tempo_bpm = (self.tempo_bpm as i32 + d as i32).clamp(20, 300) as u16;
}
InputCommand::SeedSet(seed) => {
    self.rand_seed = seed;
    self.rng_seed = seed as u64 | ((seed as u64) << 32);
}
InputCommand::ChannelSet(ch) => {
    self.midi_channel = ch.saturating_sub(1); // 1-indexed → 0-indexed
}
InputCommand::MidiDeviceName(name) => {
    self.midi_device_name = name;
}
```

Do NOT remove any existing `InputCommand` variants or `apply_command` arms —
that is handled by Task 2.1. Do NOT modify `OverlayMode`, existing fields,
or existing handlers.
