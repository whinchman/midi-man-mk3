## Description

Update `engine/src/hid.rs` to compile cleanly after the `InputCommand` variants
`OpenOverlay`, `CloseOverlay`, `ParamSelect`, `ParamSelectDelta`, and
`ParamValueDelta` are removed by Task 2.1. Replace them with the semantically
equivalent new variants `PanelParamSelect(u8)` and `PanelParamDelta(i8)`.

This task implements **Option A** from the architecture plan: replace overlay
sends with panel equivalents rather than leaving dead code stubs.

Files to touch: `engine/src/hid.rs`

**What to find in hid.rs:**

Search for all occurrences of:
- `InputCommand::OpenOverlay`
- `InputCommand::CloseOverlay`
- `InputCommand::ParamSelect`
- `InputCommand::ParamSelectDelta`
- `InputCommand::ParamValueDelta`
- `OverlayMode::` (if imported)

**Replacements:**

| Old send | New send | Notes |
|---|---|---|
| `InputCommand::OpenOverlay(_)` | Remove — focus switching from HID is not in scope for this refactor | Drop the send; the HID encoder press no longer opens an overlay |
| `InputCommand::CloseOverlay` | Remove — same reasoning | |
| `InputCommand::ParamSelect(idx)` | `InputCommand::PanelParamSelect(idx)` | Direct 1:1 replacement |
| `InputCommand::ParamSelectDelta(d)` | `InputCommand::PanelParamDelta(d as i8)` | Adjust type cast if needed |
| `InputCommand::ParamValueDelta(d)` | `InputCommand::PanelParamDelta(d)` | Semantic equivalence for value adjust |

Remove any import of `OverlayMode` from `hid.rs` if present.

The goal is zero breaking changes to the observable HID behavior for
encoder-driven param navigation. The only behavioral change is that hardware
overlay open/close gestures are silently dropped (no panel focus change from
hardware in this refactor scope).

Keep all existing HID logic untouched — only replace the specific
`InputCommand` variant sends listed above.
